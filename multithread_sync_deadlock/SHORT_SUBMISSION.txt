THREADING CONCEPTS (BRIEF)
===============================================================================

THREAD MODELS:
• User-level: Fast switching, library-managed
• Kernel-level: OS-managed, true parallelism
• Hybrid: M:N mapping, balanced approach

MULTITHREADING MODELS:
• Many-to-One: Multiple user → single kernel thread
• One-to-One: Direct mapping, higher overhead
• Many-to-Many: Flexible mapping, complex

THREADING BENEFITS:
• Responsiveness: Non-blocking execution
• Resource Sharing: Efficient memory usage
• Concurrency: Simultaneous task progress
• Parallelism: Multi-core utilization

THREADING CHALLENGES:
• Race Conditions: Shared data conflicts
• Deadlocks: Circular waiting scenarios
• Overhead: Context switching costs
• Python GIL: Limits CPU parallelism
